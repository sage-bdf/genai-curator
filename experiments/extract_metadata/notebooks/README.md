# Notebooks for Table Alignment and Analysis

This directory contains Jupyter notebooks for working with the table alignment and analysis tools.

## Available Notebooks

1. **compare_demo.ipynb**: Demonstrates how to use the CSVComparator module to compare metadata files from two different folders.
2. **example_analysis.ipynb**: Demonstrates how to analyze the aligned tables generated by the table_aligner.py script.

## Usage Notes

When running these notebooks, you'll need to update the paths to point to the correct locations in the new directory structure:

### For compare_demo.ipynb:

```python
# Update these paths to point to the correct locations
original_metadata_folder = "../data/ground_truth"
generated_metadata_folder = "../data/predicted"
```

### For example_analysis.ipynb:

```python
# Update this path to point to the correct location
output_dir = Path("../data/output")
```

## Running the Notebooks

1. Start Jupyter Notebook or JupyterLab from the project root directory.
2. Navigate to the `notebooks` directory.
3. Open the desired notebook.
4. Update the paths as described above.
5. Run the notebook cells.
